# Polza Agency - тестовое задание «Вайбкодер-аутричер»

Решение тестового задания: база B2B-компаний, персонализация через скрипт, цепочка писем и аудит присланной базы.

**Ссылка на таблицу: [клик](https://docs.google.com/spreadsheets/d/1HCIz1datSJXNpEVrzmw9jz54zpJoZP5dvyI-eraIeEs/edit?usp=sharing)**

## Результаты по заданиям

1. **Сбор базы.** 60 компаний B2B из России с отделом продаж: название, сайт, имя и должность ЛПР, email, телефон, город, сегмент. Контакты собраны с официальных сайтов компаний. Каждый email проверен: синтаксис, MX-записи (60 из 60 валидны), домен почты сверен с доменом сайта.

2. **Персонализация.** В каждой строке базы - персональный факт в 1-2 предложения и ссылка на источник, откуда он взят. Реализовано скриптом `scripts/personalize.py`: на входе список компаний, на выходе - готовая колонка «Персонализация»; промпт запрещает выдумывать, разрешён только текст с сайта компании.

3. **Цепочка писем.** Три письма от имени Polza Agency, каждое до 120 слов: знакомство с крючком (день 1), кейс под другим углом (через 3 дня), мягкий выход (через 5 дней). В письме 1 используется переменная `{{персонализация}}`. Тексты - в файле `email-sequence.md` и на листе «Цепочка писем» в таблице.

4. **Персонализация присланной базы (15 компаний).** Проверил каждую строку: нашёл 5 строк с перепутанными контактами (например, JAT и Rogen - данные перекрёстно; у «Ункомтеха» стояли чужие домены) и 1 строку под вопросом. По каждой строке подготовлены корректные контакты, персонализация и источник. Полный аудит - на листе «База 15» в таблице.

5. **Вайбкод/LLM-инженер стек.** Коротко по пунктам:

   - IDE и модели: Cursor для продуктовых задач и Claude Code для длинных автономных прогонов; модели роутирую по задаче - Claude для кода, GPT для текстов, дешёвые модели для батчей.
   - Подписки: комфортный бюджет около $60-150 в месяц: одна сильная IDE-подписка, одна топовая чат-подписка и API по потреблению вместо зоопарка из пяти сервисов.
   - Сравнение моделей: одинаковый набор из 8-10 повторяемых задач, замер ручных правок и стабильности; ощущения - только первый фильтр.
   - Тесты для новой функции: happy path, граничные случаи, регресс; для внешних скриптов - dry-run и лимиты; для LLM - повторяемость на одном входе.
   - Разрешения coding-агенту: работа в песочнице, терминал без записи наружу, база - только read-only, секреты в переменных окружения.
   - Тесты и CI/CD: линт, тесты и dry-run обязательны до мержа; до деплоя - staging и план отката; для рассылок - тестовая отправка на свой адрес.

   По количеству токенов: порядка 15 миллиардов токенов необходимо, если работать по 16 часов на протяжении 30 дней (у меня уходит примерно такое количество на мои проекты).

## Файлы

- `scripts/collect_emails.py` - сбор контактов: обход сайтов, извлечение email, телефонов и фактов для персонализации.
- `scripts/personalize.py` - персонализация через LLM (любой OpenAI-совместимый API, есть режим dry-run).
- `scripts/audit_base.py` - аудит базы перед рассылкой: сверка доменов email и сайта, MX, дубликаты, доступность сайта.
- `email-sequence.md` - цепочка из трёх писем.
- `polza-test-table.xlsx` - таблица с результатами (база, цепочка писем, база 15); копия Google Таблицы.

## Запуск скриптов

```
python scripts/collect_emails.py                                        # сбор базы (вход: data/candidates.txt)
python scripts/personalize.py --input base.csv --output base_done.csv  # персонализация
python scripts/audit_base.py --input base.csv --output audited.csv     # аудит базы
```

Требования: Python 3.8+ и curl. Для персонализации через LLM нужен ключ API в переменной `LLM_API_KEY`.
